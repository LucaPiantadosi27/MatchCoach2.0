1. OBIETTIVO

Aggiungere un'interfaccia mobile di chat tattica che permetta
all'allenatore di fare domande testuali all'assistente AI, con contesto
opzionale di schema e partita, e pulsante per input vocale (placeholder).

- Modello `ChatMessage` e `ChatSession` con serializzazione JSON

- `TacticalChatScreen` con:
  - lista messaggi user/assistant
  - input testuale
  - pulsante invio
  - pulsante microfono (placeholder)
  - indicatori di contesto (schema e partita)
- Navigazione dalla `TacticalBoardScreen` via icona chat in AppBar
- Test unitari del `ChatProvider`

5. FLUSSO DI FUNZIONAMENTO

Aprire chat:
  TacticalBoardScreen → tap icona chat → TacticalChatScreen

Invio messaggio:
  Utente scrive → tap invio
  → ChatProvider aggiunge ChatMessage.user
  → AssistantClient.post('/assistant/ask')
  → Backend (AssistantService) elabora
  → ChatProvider aggiunge ChatMessage.assistant con risposta

Input vocale:
  Tap microfono → placeholder "Input vocale non ancora implementato"

6. API / ENDPOINT

POST http://localhost:3000/api/assistant/ask
  Headers:
    Authorization: Bearer <token>
    Content-Type: application/json
  Body:
    {
      "channel": "A" | "B",
      "question": "string",
      "schemeId?": "string"
    }
  Response:
    {
      "answer": "string",
      "sources?": ["scheme:<id>"]
    }

7. MODELLO DATI

ChatMessage:
  - id, role (user/assistant/system), text, timestamp, sources?

ChatSession:
  - id, schemeId?, matchContext?, messages

Navigare:

  3. Scrivi domanda e invia
  4. Il contesto schema viene attivato se `schemeId` è impostato

11. DECISIONI TECNICHE

- Riverpod per stato chat: coerente con il resto dell'app
- `AssistantClient` astratto e overridable: facilita test
- Schermata a sè stante: mantiene separazione di responsabilità
- Pulsante microfono placeholder: input vocale richiede package e
  permission futuri (MS14)
- Contesto match: stringa libera per allenatore, non ancora legata a
  modello dati partita
- Base URL `localhost:3000` per dev: in produzione sarà sostituito
  da variabile d'ambiente

12. LIMITAZIONI NOTE

- Input vocale non implementato
- Nessun salvataggio storico delle chat
- Nessuna persistenza locale dei messaggi
- Base URL hardcoded per dev
- Non è integrato un vero flusso di autenticazione JWT lato mobile
- Nessuna gestione di connessione assente o timeout specifico UI
